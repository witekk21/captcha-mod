# Captcha Auto-Filler Mod

Mod dla Minecraft 1.21.4, ktorego automatycznie rozwiazuje captcha.

## Funkcje

- Automatyczne odczytywanie kodu captcha ze srodka ekranu
- Automatyczne wysylanie `/captcha <kod>` do czatu
- Cooldown aby uniknac duplikatow

## Instalacja

1. Umiesz plik JAR w folderze mods
2. Uruchom Minecraft z NeoForge
